Открытый инструментарий для упрощенной локализации игры GTA San Andreas, контроля ошибок в переводе и озвучки, для легкого объединения нескольких переводов в единое целое. Набор утилит для работы со звуком, текстурами, текстами игры.

# Зачем?

Существует множество локализаций GTA San Andreas, в частности, на русский язык. Все различного качества, с различным уровнем ошибок, с разным уровнем недоделанности. Но самое главное - все они существуют как законченные и закрытые проекты, без исходников, без точного технического описания, без возможности быстро найти и устранить ошибки в них. Как результат, каждая следующая локализация - это работа с нуля, вместе с разработкой всех последующих утилит для пересборки игровых ресурсов и скриптов. Возможно, даже контроля качества, если он будет.

# Направления работы

1. Работа с текстом: извлечение, сравнение, упаковка текста. Сериализация субтитров, утилиты diff/patch для работы с субтитрами.
2. Работа со звуком: извлечение, склейка атласов, нарезка атласов, упаковка в игру. Сериализация таймингов/субтитров. Озвучка средствами TTS в реальном времени и виде записей как средство контроля перевода/укладки текста в речь.
3. Работа с текстурами: поиск текстур с текстом, OCR, сериализация идентификаторов текстур/координат/шрифтов, перезапекание текстур.
4. Работа с моделями: поиск моделей с геометрией в виде текста (объемные буквы), моделей с 2DFX (надписи на столбах, указателях)
5. Создание упаковщика, который позволит выбрать несколько вариантов локализации/их частей и быстро установить все локализации одновременно, включая перерисовку текстур / наложение звука по запросу.

## Автоматическое прохождение игры

Скрипт поллит текущее состояние main-сценария, возможно поллит текущие субтитры и на основе этого что-то делает. Например, при mission==intro, при появление титров "садись на велосипед", мы телепортируемся на точку перед домом и таким образом intro-миссия завершается. Начинается новая миссия со Смоуком - мы ничего не делаем. Нам приказывают сесть на велосипед и следовать за райдером - в принципе можно попробовать это сделать, но не обязательно, достаточно перемещать Сиджея рядом с моделькой райдера на расстояннии 3 метра, можно его где-то в войдухе подвесить. Главное, чтобы Райдер не ждал его и продолжал свой скрипт до Грув Стрит. Входим в зону красного маркера - телепортируемся на него - миссия завершена. Не ранее, если телепортнуться на красный маркер сразу, то Райдер будет ждать Сиджея где-то в городе и миссия будет висеть. И так далее, до конца игры. Желательно, выковыривая из игры максимум звуков: например, можно что-то поджигать вокруг, или сбрасывать с неба автомобили. Само собой, раз в минуту можно-нужно переключать время / погоду / розыск. Можно переключать одежду/стату персонажа/жир, чтобы вызывать разные реакции. Вообще идеально было бы доёбываться до прохожих и давать им не только отритцательные ответы, но и положительные (больше разнообразных фраз). 

Возможно, имеет смысл сделать несколько режимов: прохождение сюжета отдельно, доебывание до прохожих отдельно, возможно реализация каких-то других механизмов поведения игрока.

Цель: максимально триггерить игру на использование речевых банков, стресс-тест игры, поиск вылета игры.

## Запись субтитров

Мод, который бы писал в файлик лог текущих субтитров/подсказок/менюшек/любых текстов на экране в формате ASS, чтобы потом можно было это наложить на видео из игры и тайминг жестко совпадал. Для синхронизации титров можно побибикать, чтобы в видеозаписи тоже было к чему прицепиться. Должно получиться сотни часов видеозаписей с разметкой что где куда.

Полученные видеоматериалы можно использовать как для контроля состояния получившейся локализации, так и для скармливания нейросетям для автоматической проверки.
